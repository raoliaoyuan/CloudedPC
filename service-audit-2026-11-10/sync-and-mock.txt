1: # sync-server-trpc-go
2: 
3: 基于 tRPC-Go 框架的文件同步服务，负责将腾讯文档网盘（docs.qq.com v6 SMH API）的远端文件单向拉取到本地，并支持 chat-history 会话记录的双向同步。
4: 
5: ## 项目概述
6: 
7: sync-server-trpc-go 是 sync-server（C++ mcp++ 版）的 Go 重写版本，采用单进程 + tRPC-Go 插件体系，替代原来的 mcd/ccd/dcc/smcd 四件套 + watchdog 多进程模型。
8: 
9: **核心能力：**
10: 
11: | 子系统 | 职责 | 设计文档 |
12: |--------|------|---------|
13: [credential-related line omitted]
14: | **Sync** | list → diff → pull → delete 五阶段流程，per-project 串行，30s 心跳驱动 | `docs/design/20-sync.md` |
15: | **Chat-History** | 会话记录 push-only 单向上传 + cap 驱逐，60s list_tick 对账 | `docs/design/21-chat-history-sync.md` |
16: | **Inspection** | 24h 周期全量本地 walk + SHA1 校验（IN_SYNC / DIRTY / ORPHAN） | `docs/design/30-inspection.md` |
17: | **Health** | HTTP 健康端点 + RPC 探活 | `docs/design/40-health.md` |

105: ## 编译
106: 
107: 用 `-X` 把**时间戳版本**注入 `processinfo.version`（未注入时 fallback `dev`）；该版本会进 User-Agent 与 obs 监控的 `version` 维度，用于线上区分构建批次：
108: 
109: ```bash
110: cd sync-server-trpc-go/
111: VERSION=$(date +%Y%m%d_%H%M%S)   # 纯时间戳版本，如 20260622_175100
112: CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath \
113:   -ldflags="-s -w -X git.woa.com/cloudMeldSystem/sync-server-trpc-go/internal/processinfo.version=${VERSION}" \
114:   -o pkg/bin/sync_server ./cmd/sync-server
115: ```
116: 
117: 产出：`pkg/bin/sync_server`（~17MB，纯静态链接、stripped）。`-X` 后跟变量全路径是 Go 链接器的硬要求；版本**值**仅用时间戳，不嵌任何 git 仓前缀。
118: 
119: ## 打包
120: 
121: 打包后解压即得 `sync_server/` 扁平目录（与现网部署路径 `/usr/local/tna/sync_server/` 对齐），无 `pkg/` 中间层：
122: 
123: ```bash
124: TAG=$(date +%Y%m%d_%H%M%S)
125: tar -czf "sync-server-trpc-go-${TAG}.tar.gz" \
126:   --exclude='pkg/log/*.log' \
127:   --exclude='pkg/*.pid' \
128:   --exclude='pkg/local_runtime' \
129:   --exclude='pkg/README.md' \
130:   --transform='s,^README.md$,sync_server/README.md,' \
131:   --transform='s,^pkg,sync_server,' \
132:   -C . pkg/ README.md
133: ```
134: 
135: > 两条 `--transform` 分别把仓库根 `README.md` 与 `pkg/` 前缀改写成 `sync_server/`；`pkg/README.md` 排除是为了避免与仓库根 README 冲突；`local_runtime/` 是运行时目录（meta/tmp/deleted），由首次运行自动创建，不入包。
136: >
137: > ⚠️ **包顶层结构必须是 `sync_server/`（不是 `pkg/`）**——与现网部署路径 `/usr/local/tna/sync_server/` 对齐。请统一用 `bash pkg/scripts/package.sh`（已内置 `--transform`）或上面的完整命令打包；**切勿直接 `tar czf xxx.tar.gz pkg`**，否则顶层会是 `pkg/`、解压路径错位。
138: 
139: 包内结构（解压后）：
140: 
141: ```
142: sync_server/
143: ├── bin/sync_server           # 静态 ELF 64-bit x86-64 二进制
144: ├── conf/
145: │   ├── trpc_go.yaml          # 现网（Production）配置
146: │   └── trpc_go_test.yaml     # 测试/沙盒配置
147: ├── scripts/
148: │   ├── start.sh              # 启动（nohup 后台 + pid file）
149: │   ├── stop.sh               # 停止（SIGTERM → 10s grace → SIGKILL）
150: │   ├── restart.sh            # 重启（stop + start）
151: │   └── status.sh             # 状态查看（pid + ps + 日志尾 30 行）
152: ├── log/                      # 运行时日志目录（空，运行时写入）
153: └── README.md                 # 本说明（仓库根 README.md）
154: ```
155: 
156: > 解压后还会运行时产生 `local_runtime/`（meta/tmp/deleted）、`sync_server.pid`、`trpc.log` 等，这些都不入包。
